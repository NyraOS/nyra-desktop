# Security policy

nyra-desktop is the desktop image of an operating system, so we take reports seriously and handle
them privately.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Include what you found, how to reproduce it, and the commit or image you tested. We will confirm the
report, keep you informed, and credit you in the fix unless you prefer otherwise.

## Supported versions

The project is in early development and nothing is released to users yet. Only the `main` branch is
supported.

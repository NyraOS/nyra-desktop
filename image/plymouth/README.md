# Boot screen drawings

The sources of the PNG files in `image/files/usr/share/plymouth/themes/nyra` (`sh make-assets.sh`
renders them; `docs/IMAGE.md`, "Boot screen").

| File | What |
|---|---|
| `logo.svg` | The Nyra logo with the moon in the accent colour, as drawn in the project's brand files, kept byte for byte |
| `ring-track.svg`, `ring-arc.svg` | The loading ring: a faint full circle, and the arc the theme turns |

The Nyra OS logo is a trademark of Wagg Software and is not covered by this repository's GPL licence. It
may be used to refer to Nyra OS, not for other products. The ring drawings are plain geometry.

# nyra-desktop

The desktop image of [Nyra OS](https://nyraos.com): KDE Plasma layered on top of a pinned
[nyra-base](https://github.com/NyraOS/nyra-base) image, with its own sealed UKI.

Early work: nothing here is ready for users yet. How the image is built: [`docs/IMAGE.md`](docs/IMAGE.md);
how the desktop is tested: [`docs/TESTING.md`](docs/TESTING.md).
